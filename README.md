<summary>Working with AI coders</summary>

**Clean statistics can miss the goal entirely.** I rebuilt a pitch-detection
engine to drop an ML dependency. Note counts and durations passed every
threshold; the output didn't sound like the source. I kept the model and
shelved the rewrite. The test that matters is whether a person recognizes
the piece.

**A good agent's deviation can beat the brief.** A build session amended my
own format spec mid-run — a new tier for tools that bundle a model. It was
better reasoned than the rule it broke, so it went into the canonical spec
instead of being reverted.

**Simulated measurement is a hypothesis.** A test harness predicted 44.9% of
spectral energy below 226 Hz. The first real 46-minute recording measured
23.8% — the simulation counted oscillator fundamentals and missed the added
partials. Both numbers stay in the log.
